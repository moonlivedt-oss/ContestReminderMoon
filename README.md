Трей-напоминалка о конкурсах с автозаписью. Проблема, которую решает: лень
куда-то записывать конкурсы, а в уме они не держатся. Поэтому приложение само
ловит инфу и напоминает.

## Как ловит информацию (автозапись)

Два пути, работают одновременно:

1. **Слежение за буфером обмена.** Копируешь пост или ссылку конкурса (то, что и
   так делаешь) — приложение разбирает текст и, если это похоже на конкурс,
   показывает карточку с уже заполненными полями. Проверил, нажал «Сохранить».
2. **OCR-захват области экрана** по горячей клавише (по умолчанию `Ctrl+Alt+C`).
   Выделяешь мышью область (пост-картинка в Telegram, баннер) — текст
   распознаётся встроенным Windows OCR и разбирается так же.

Из текста автоматически достаются:

- **заголовок** — первая осмысленная строка;
- **ссылка** — первая `http(s)`-ссылка, а если её нет - адрес без схемы, как его
  пишут в постах (`vk.com/club1`, `t.me/chan`, `www.site.ru`);
- **дедлайн** — даты в русских и английских формах: `до 15 сентября`,
  `дедлайн 20.09.2026`, `ends September 30`, `2026-12-01 18:00`, а также
  относительные: `осталось 3 дня`, `через 2 недели`, `in 5 days`. Если год не
  указан — берётся ближайший будущий; если нет времени — 23:59.

## Напоминания

На каждый конкурс — свой набор напоминаний (галочками): за 3 дня / за 1 день /
за 6 ч / за 1 час / за 15 мин / в момент. По умолчанию: за день, за час и в
момент. Уведомления приходят всплывающими сообщениями из системного трея. Если
приложение было выключено и пропущено несколько порогов — покажется одно
уведомление (самое срочное), а не пачка.

## Установка и запуск

Нужна Windows 10/11. Скачайте репозиторий (Code -> Download ZIP или `git clone`) и
дважды щёлкните **`Запуск.bat`**. Он всё настроит сам:

1. найдёт Python 3.11 или 3.12 (через `py` или `python` в PATH);
2. если Python нет - предложит поставить 3.11 через `winget`;
3. при первом запуске поставит пакеты из `requirements.txt` (`PyQt6`, `mss`, `winsdk`,
   `Pillow`; нужен интернет, один раз);
4. запустит программу без окна консоли.

Python 3.13+ не подходит: под него нет пакета `winsdk` (Windows OCR).

Окно живёт в трее: закрытие сворачивает его в фон, выход - через меню иконки в
трее (правый клик -> «Выход»). Там же галочка **«Запускать вместе с Windows»**:
программа стартует при входе в систему сразу в трее, без окна (строка в
`HKCU\...\Run`, права администратора не нужны). Данные лежат в
`%APPDATA%\ContestReminder\` (`contests.json`, `settings.json`).

Вручную и для разработки:

```powershell
py -3.11 -m pip install -r requirements.txt
py -3.11 run.pyw            # ключ --tray - стартовать свёрнутым в трей
py -3.11 -m pip install pytest ruff
py -3.11 -m pytest          # тесты парсера, модели и планировщика (Qt offscreen)
py -3.11 -m ruff check .
```

## Требования к системе

- Windows 10/11 с языковыми пакетами OCR (ru, en) — обычно уже стоят. Если OCR
  ругается — доставь язык в «Параметры → Время и язык → Язык».
- Горячая клавиша регистрируется глобально через Win32; если она занята другим
  приложением, OCR-захват можно вызвать кнопкой в окне или пунктом меню трея.

## Структура

```
contestreminder/
  parser.py          разбор текста -> заголовок/ссылка/дедлайн (ядро автозаписи)
  models.py          модель Contest + форматтеры дат и обратного отсчёта
  config.py          %APPDATA%: настройки и хранилище конкурсов
  clipboard_watch.py слежение за буфером обмена
  hotkey.py          глобальная горячая клавиша (Win32 RegisterHotKey, ctypes)
  region.py          выбор области экрана под OCR
  ocr.py             Windows OCR (winsdk) + захват mss
  reminders.py       планировщик уведомлений
  editor.py          диалог добавления/правки (он же карточка подтверждения)
  theme.py           палитра Catppuccin Mocha + QSS
  icons.py           значки из assets/ и запасной векторный колокольчик
  assets/            иконка приложения и значки кнопок
  autostart.py       автозапуск с Windows (HKCU\...\Run, ключ --tray)
  app.py             окно, трей, связывание всего
tests/               pytest: парсер, модель, планировщик
run.pyw              точка входа без консоли
Запуск.bat           установка и запуск двойным кликом
```
