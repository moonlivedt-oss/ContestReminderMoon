## [Unreleased]

### Оформление
- **Тема и палитра**, как в окне документации C++: режим Авто / Светлая / Тёмная / Сепия
  (плитки с мини-превью) и девять палитр с пейзажами (Catppuccin, Tokyo Night, Dracula, Nord,
  Gruvbox, Rosé Pine, One Dark, Лес, Закат). В светлом режиме и сепии палитра меняет только
  акцент, яркость подбирается до контраста 4,5:1. Тема видна сразу, «Отмена» её возвращает;
  быстрый выбор - меню «…» -> «Тема» / «Палитра».
- **Новая карточка конкурса:** полоса срочности слева, отсчёт крупно справа, дата, ссылка и
  иконки действий в одной строке, шкала «сколько времени прошло от записи до дедлайна».
  Напоминания конкурса - в подсказке к отсчёту.
- Шапка с колокольчиком и сводкой («скоро: 2 | ближайший через 4 ч»), поиск со значком,
  группы со счётчиками, подвал с подсказками клавиш.
- Пустой список, пустой поиск и пустые «Выполненные» - с маскотами из библиотеки и кнопками.
- Настройки разложены по вкладкам: «Основные», «Оформление», «Система».

### Структура
- Пакет разложен по слоям: `core/` (логика без Qt), `services/` (сеть, Windows, C++-часть),
  `ui/` (окна). Главное окно вынесено из `app.py` в `ui/main_window.py`, карточка - в
  `ui/card.py`, таймер напоминаний - в `services/scheduler.py` (чистая логика осталась в
  `core/reminders.py`). Запуск как модуля: `py -3.11 -m contestreminder`.
- `tools/screenshots.py` снимает все окна для README на демо-данных.

### Исправлено
- «Выход» из трея не срабатывал, пока открыто окно: Qt 6 перед выходом просит окна
  закрыться, а наше пряталось в трей и тем самым отменяло выход.
- Программа падала, если карточку «Сохранить?» закрыть раньше, чем дочиталась страница по
  ссылке, и при выходе во время загрузки страницы. Загрузка теперь в обычном фоновом потоке,
  карточка проверяет, что она ещё открыта.
- Ошибка в обработчике окна больше не закрывает программу: она пишется в
  `%APPDATA%\ContestReminder\errors.log`.

## [1.3.0] - 2026-10-11

### C++: уведомления Windows и лёгкий сторож
- Новая нативная часть `crnative.exe` (C++20, C++/WinRT, около 400 КБ, без сторонних
  библиотек), исходник `native/crnative.cpp`.
- **Уведомления Windows с кнопками** «Открыть», «Через 1 ч», «Завтра», «Готово»: они остаются в
  Центре уведомлений, если вы отошли от компьютера. Срочные (дедлайн сейчас, отложенное) висят
  на экране, пока не нажмёте. Кнопки работают через протокол `contestreminder://` - и когда
  программа запущена (передают действие через мост), и когда закрыта (crnative сам правит
  `contests.json` или запускает программу).
- **Лёгкий фоновый режим** (настройки -> Система): закрытие окна выключает программу целиком,
  а напоминает сторож `crnative.exe watch` - около 3 МБ личной памяти и 0,2 МБ рабочего набора
  в покое. Сторож спит до ближайшего порога, просыпается, когда меняется `contests.json`, и
  молчит, пока запущена основная программа. Автозапуск с Windows в этом режиме запускает сторожа.
- Вид уведомлений «Как лучше» (по умолчанию): уведомления Windows, если есть C++-часть, иначе
  карточки программы, как раньше.
- C++-часть входит в `ContestReminder.exe` и ставится в `%LOCALAPPDATA%\ContestReminder\bin`.
  Из исходников её собирает `native\build.cmd` (MSVC + Windows SDK); без неё программа работает
  как в 1.2.
- CI собирает C++ на MSVC и гоняет его самопроверку; самопроверка exe проверяет и C++-часть.

## [1.2.0] - 2026-10-11

### Автоматика
- Найденный конкурс больше не открывает модальное окно на каждое копирование: в углу
  экрана появляется карточка «Сохранить / Изменить / Не надо». Режимы в настройках:
  карточка, «сохранять сразу» с кнопкой «Отменить», окно правки.
- Дубли (та же ссылка без utm-меток или почти то же название) не предлагаются повторно;
  если у дубля новый срок - карточка «Обновить срок».
- Если в посте нет срока или название общее, программа в фоне читает страницу по ссылке
  (og:title, og:description, текст) и дополняет. Посты t.me читаются без входа. Кнопка
  «По ссылке» в окне правки и «Уточнить по ссылке» в меню карточки.
- Сводка дня в заданное время: дедлайны на ближайшие дни.
- Прошедшие конкурсы через N дней (по умолчанию 3) сами уходят в «Выполненные».
- Обычные копирования с одной датой больше не вызывают предложение: нужно слово-маркер
  или пара «дата + ссылка».

### Парсер
- Из нескольких дат выбирается дедлайн: даты после «до / дедлайн / ends / bis» важнее,
  после «с / старт / итоги» - отбрасываются. Диапазоны «с 1 по 15 ноября».
- Новые формы: «сегодня / завтра / послезавтра», «до пятницы», «до конца недели / месяца /
  года», «15-го октября», ISO с временем.
- Время берётся рядом с датой, а не первое в тексте; «18.00» - время только после «в».
- «3.5 млн» больше не превращается в 3 мая, «market» - в март.
- Заголовок - первая фраза поста, без эмодзи и хэштегов.
- Украинский и немецкий: месяцы, дни недели, слова-маркеры, относительные сроки.

### Удобство
- Напоминание - карточка с кнопками «Открыть», «Отложить» (15 мин, 1 ч, 3 ч, до завтра
  9:00), «Готово» и звуком; можно вернуть обычные уведомления Windows.
- Окно: группы по сроку, поиск, фильтры «Активные / Выполненные / Все», клик по названию
  открывает ссылку, меню по правому клику, удаление с «Вернуть».
- Трей: ближайшие дедлайны в меню и в подсказке значка.
- Окно настроек: автозапись, клавиша OCR, язык OCR, напоминания по умолчанию, вид
  уведомлений, звук, сводка дня, автозакрытие, язык, автозапуск.
- Экспорт в календарь (.ics) для одного конкурса и для всех; резервная копия и
  восстановление.
- Вторая копия программы не запускается, а показывает окно первой.
- Настройки и список пишутся атомарно; битый файл откладывается как *.broken.json.

### Языки
- Интерфейс на русском, английском, украинском и немецком (по умолчанию как в Windows),
  переключение без перезапуска. Тест проверяет, что переведена каждая строка.
- JavaScript: userscript `browser/contestreminder.user.js` и закладка для браузера -
  выделенный пост уходит в программу. PowerShell: `tools/cr.ps1`.
- Локальный мост `127.0.0.1:47615` с секретным ключом и проверкой Host.

## [1.1.0] - 2026-10-11

### Добавлено
- Автозапуск вместе с Windows: галочка в меню трея. Программа стартует при входе в
  систему сразу в трее (ключ `--tray`), без прав администратора.
- Ссылки без `http(s)://`, как их пишут в постах (`vk.com/club1`, `t.me/chan`,
  `www.site.ru`), попадают в карточку с подставленной схемой.
- `Запуск.bat` настраивает всё сам: ищет Python 3.11/3.12, предлагает поставить его
  через winget, при первом запуске ставит пакеты из `requirements.txt`.
- Тесты pytest (парсер, модель, планировщик напоминаний), ruff, GitHub Actions.
- LICENSE (MIT), `pyproject.toml`, `.gitignore`, снимок окна в README.

### Изменено
- Карточка конкурса компактнее: «Готово / Изменить / Удалить» одной строкой рядом со
  ссылкой; у кнопок значки из библиотеки картинок автора.
- Иконка окна и трея - колокольчик из той же библиотеки.
- Заголовок без лишней черты: «активных N из M».

### Исправлено
- Двойные пробелы в заголовке, когда из строки вырезана ссылка.
