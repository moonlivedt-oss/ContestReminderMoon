# PLAN — ContestReminder

Resume-файл проекта. Что сделано, что можно доработать.

## Что это
Трей-напоминалка о конкурсах с автозаписью. PyQt6, Python 3.11 (winsdk+mss),
палитра Catppuccin Mocha. Данные в `%APPDATA%\ContestReminder\`.

## Готово (v1, проверено)
- Парсер текста -> заголовок/ссылка/дедлайн (RU+EN даты, относительные сроки,
  привязка времени, достройка года). Ядро автозаписи. Самотест: `py -3.11 -m contestreminder.parser`.
- Слежение за буфером обмена: копируешь пост -> если похоже на конкурс,
  всплывает карточка с заполненными полями.
- OCR-захват области по глобальной горячей клавише (Win32 RegisterHotKey),
  встроенный Windows OCR. Кнопка/пункт трея — запасной вызов.
- Планировщик: несколько напоминаний на конкурс; при простое приложения не
  сыплет пачкой (показывает самое срочное). Проверено юнит-прогоном.
- Окно со списком карточек, добавление/правка/удаление/«готово», трей,
  сворачивание в трей, сохранение геометрии и настроек.

## Сделано в 1.1 (2026-10-11)
- Автозапуск с Windows (галочка в трее, HKCU Run, старт сразу в трей `--tray`).
- Ссылки без схемы (vk.com/..., t.me/..., www.) распознаются.
- Карточки компактнее: действия одной строкой, значки из библиотеки картинок.
- `Запуск.bat` сам ищет Python 3.11/3.12, ставит пакеты при первом запуске.
- Тесты pytest (парсер, модель, планировщик), ruff, GitHub Actions.

## Запуск
`Запуск.bat` (сам ставит зависимости). Тесты: `py -3.11 -m pytest` (Qt offscreen в conftest).
